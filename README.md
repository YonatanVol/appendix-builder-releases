# בונה תיקי נספחים: קבצי התקנה

המאגר הזה מכיל רק את קובצי ההתקנה של התוכנה ואת קובצי העדכון שלה. אין בו קוד מקור.

**להורדה:** בגרסה האחרונה, תחת [Releases](https://github.com/YonatanVol/appendix-builder-releases/releases/latest),
מורידים את `AppendixBuilder-Setup-<גרסה>.exe` ולוחצים עליו פעמיים.

התוכנה אינה חתומה דיגיטלית, ולכן בפעם הראשונה Windows מציג "Windows protected your PC". בוחרים
**More info** ואז **Run anyway**. אחרי ההתקנה התוכנה מתעדכנת לבד מהמאגר הזה.

Every file here is published by the build pipeline after the installer has been built, installed and
run on Windows. Nothing is uploaded by hand.
